# Lucid Chat — Astra / Aurora Pavilion

선택된 A안의 실제 서비스 구현. 작업 브랜치는 `codex/aurora-uiux-astra`, 기준 커밋은 `be05520`이다. 원본 작업 디렉터리와 분리한 `C:/Users/zapza/Desktop/LucidChat-Front/LucidChat-Astra` 워크트리에서 작업했다.

## 실행과 비교

```powershell
Set-Location C:/Users/zapza/Desktop/LucidChat-Front/LucidChat-Astra
npm ci
npm run dev -- --host localhost --port 5174 --strictPort
```

- 실제 로비: http://localhost:5174/
- 인트로·상태 검수: http://localhost:5174/__design
- 실제 채팅 컴포넌트 체험: http://localhost:5174/__design/chat
- 제작·보관함·스토리 준비 체험: http://localhost:5174/__design/secondary

현재 로컬 `.env.development.local`은 서비스의 공개 API와 CDN을 사용한다. 다른 워크트리에서 재현할 때 필요한 값:

```dotenv
VITE_API_BASE_URL=https://api.lucid-chat.com/api/v1
VITE_ASSET_BASE_URL=https://assets.lucid-chat.com
VITE_LOCAL_ASSET_FALLBACK=0
```

공개 탐색 화면은 실제 데이터다. 개발 체험 경로는 실제 컴포넌트에 로컬 예시 상태를 전달하며 대화·제작·결제 요청을 보내지 않는다. 개발 경로는 `import.meta.env.DEV` 조건과 lazy import로 묶여 프로덕션 JavaScript에 포함되지 않는다. 실제 계정의 로그인·과금·생성 동작은 운영 API로 이어지므로 화면 비교에는 개발 체험을 사용할 수 있다.

## 구현한 경험

- **로비:** 라벤더와 청록 간접광, 아치 구조, 느린 배경 이동, `LUCID CHAT` 로고. 실제 캐릭터를 선택하는 대표 영역과 이어하기 영역, 명확한 추천·창작·세계관 구분.
- **캐릭터:** 검증된 오리지널 캐릭터는 장소 배경·누끼·빛·스크림을 조합한다. UGC 커버 이미지는 원래 배경을 유지한다. 이미지 오류에는 그라데이션과 이니셜을 표시한다.
- **프로필:** 넓은 초상 영역, 읽기 쉬운 소개와 상세 정보, 고정된 대화 시작 버튼. 모바일에서는 세로 구성과 내부 스크롤을 사용한다.
- **진입:** 기존 네 캐릭터의 전용 영상을 우선 재생한다. 영상이 없는 캐릭터·세계관은 공용 오로라 공간 연출을 사용한다. 건너뛰기·오류·지연·재시도를 데이터 준비와 분리한다. 상세 계약은 [AURORA_ENTRY_EXPERIENCE.md](AURORA_ENTRY_EXPERIENCE.md).
- **채팅:** 대사·나레이션·속마음의 구분, 읽기 영역과 입력 영역의 위계, 차분한 관계·에너지 표시, 긴 대사와 응답 대기 처리. 모바일 시트는 콘텐츠 스크롤과 닫기 드래그를 분리한다.
- **스토리·제작·보관함:** 세계관 카드와 두 진입 방식, 제작 초대·진행 상태·카드, 캐릭터·세계관 입력 흐름, 대화 기록·빈 상태, 첫 만남 및 로그인 화면을 같은 색·타입·버튼 체계로 맞췄다. 제작 비용은 실제 단계별 비용을 표시한다.
- **접근성·모션:** 전역 키보드 포커스, 주요 모달의 Tab/Escape·포커스 복원, 44px 조작 영역, 선택 버튼 상태, 동작 줄이기 설정 지원. 기존 Framer Motion과 CSS를 사용하며 새 애니메이션 라이브러리를 추가하지 않았다.

## 검증과 범위

```powershell
npm run build
npm run check:tdz
npm run check:entry
git diff --check
```

실제 브라우저에서 1280px 데스크톱, 768px 태블릿, 390px·360px 모바일 화면을 확인했다. 확인한 흐름은 공개 로비·프로필·스토리·로그인 안내, 채팅 일반·긴 대사·에너지 부족·관계 패널, 제작 입력·비용 안내, 보관함 예시, 인트로 대기 후 자동 전환·오류 재시도·전용 영상 재생·영상 실패 시 대체 연출이다.

인트로 자동 검사는 69개 조건을 검사하며 실제 페이지 함수에 제어된 요청·스트림을 전달한다. 전체 브라우저 E2E나 실계정 서버 통합 검사를 대체하지 않는다. 동작 줄이기는 구현·코드 검수 범위이며 모든 기기의 WebView에서 직접 실행한 것은 아니다.

2026-09-10 최종 결과: 프로덕션 빌드 통과, TDZ 135개 파일 통과, 인트로 69개 검사 통과, 변경 공백 검사 통과. 신규 체험·로비 컴포넌트·유틸리티·인트로 파일의 ESLint 통과. 프로덕션 JavaScript에 개발 경로·예시 화면 문구가 없는 것도 확인했다.

기존 저장소의 전체 ESLint 기준선은 통과 상태가 아니다. 신규 개발 체험·유틸리티·인트로 파일을 검사하고 수정된 기존 파일은 기준선과 비교했다. 기존 번들 크기·동적 import 중복 경고도 남는다.

이번 변경의 중심은 로비에서 캐릭터·스토리를 고르고 대화·제작·보관함으로 이어지는 주요 경험이다. 결제·성인인증·지원센터·극장 전용 상세 화면 전체를 새 레이아웃으로 교체하지는 않았다. 인증·딥링크·과금 API 계약을 유지했으며 실제 결제·유료 대화·UGC 생성은 실행하지 않았다.

운영 배포·병합·커밋은 하지 않았다. 이 워크트리의 저장된 변경을 비교·선택 후 적용할 수 있다.
