# 오로라 진입 경험

`EntryExperience`는 화면 연출만 담당한다. API 호출·대화 생성·재화 처리는 기존 `ChatPage` / `ChatPageV2`가 담당한다.

## 진입 규칙

- 기록이 있는 방은 인트로를 반복하지 않고 기존 장면을 복원한다.
- 기록 조회가 성공했고 결과가 빈 배열인 방에서만 첫 만남을 시작한다. 조회 실패나 잘못된 응답을 빈 방으로 간주하지 않는다.
- 연출 종료와 첫 장면 준비는 별도 조건이다. 두 조건을 모두 만족해야 채팅을 공개한다. 건너뛰기와 Escape는 연출만 끝낸다.
- V1은 준비된 나레이션 → 인사 순서를 유지하며, 연출 중에는 장면 큐를 소비하거나 대사를 타이핑하지 않는다.
- V2는 `first_scene` 또는 `final_result`의 첫 유효 장면으로 준비를 완료한다. `final_result`만 도착해도 첫 장면을 복구한다. 중복 최종 이벤트는 기록에 한 번만 반영한다.
- 빈 스트림·첫 장면 이전 실패는 오류 화면으로 유지한다. 자동 재시도 루프를 만들지 않는다. V2의 명시적 재시도는 기록을 다시 확인하므로 서버에 이미 저장된 오프닝을 복원할 수 있다.
- 방 전환·언마운트는 해당 오프닝 요청을 중단하고 이후 도착한 이벤트를 무시한다. SSE 종료는 자신의 요청 토큰만 해제한다.

## 전용 영상과 공용 연출

`src/utils/introPresentation.js`가 명시적 영상 목록이다. 현재 아이리·연화·태리·루나의 `/videos/characters/{slug}/intro.mp4`를 등록했다. 세계관 영상은 검증된 파일이 추가되면 `WORLD_INTRO_VIDEOS`에 세계관 ID와 경로를 등록한다. 실제 배포된 에셋이 없는 경로를 추측하거나 다른 캐릭터의 영상을 대신 재생하지 않는다.

전용 영상이 없으면 공용 공간 연출을 재생한다. 영상 오류·자동 재생 거절·첫 재생 3.5초 초과 시에도 공용 연출로 복구한다. 재생 시작 후에는 45초 상한을 둔다. 이 타이머는 연출에만 적용되며 데이터 준비를 강제로 완료하지 않는다.

공용 연출은 2.8초, 공개 페이드는 0.72초다. 시스템의 동작 줄이기 설정에서는 영상과 공간 확대를 생략하고 짧은 페이드만 사용한다. 준비가 14초 이상 걸리면 지연 안내와 로비 이동을 제공한다.

다이얼로그는 배경을 inert 처리하고 키보드 포커스를 내부에 유지한다. 닫힐 때 기존 inert 값과 포커스를 복원한다. 영상 소스는 cleanup 시 해제하고 React StrictMode의 effect 재실행 시 다시 설정한다.

## 검증

```sh
node scripts/check-entry-experience.mjs
npm run check:tdz
```

회귀 스크립트는 실제 페이지 함수와 미디어 effect를 추출해 제어 가능한 요청·스트림으로 실행한다. 준비 조건, 중복 호출, 큐 순서, 빈/비정상 응답, 최종 이벤트만 수신, 실패·취소·방 전환, 중복 최종 이벤트, 영상 소스 복구를 검사한다. 실제 계정이나 유료 대화 생성 요청은 사용하지 않는다.

개발 전용 `/__design` 화면에서 정상·지연·오류·전용 영상·영상 실패 연출을 직접 확인할 수 있다. 자동 회귀 검사는 브라우저의 실제 영상 코덱 지원이나 화면 구성 검수를 대신하지 않는다.
